# LeetCode C++ Solutions

Kumpulan solusi pribadi untuk berbagai soal di [LeetCode](https://leetcode.com/) menggunakan C++. Sebagai problem solver di LeetCode, saya menggunakan repository ini untuk belajar algoritma, data structure, dan teknik problem solving secara bertahap.

Jika Anda menemukan cara yang lebih efisien atau rapi, silakan bandingkan/eksperimen sendiri di local — repo ini sengaja dibuat sederhana dan fokus ke latihan.

## Struktur Repository

- Setiap file merepresentasikan satu soal LeetCode.
- Nama file mengikuti pola: `<nomor>.<judul_pendek>.cpp`.
- Tidak ada dependency eksternal selain standard library C++.

Contoh isi folder saat ini (hanya beberapa file pertama):

- `1.two_sum.cpp`
- `2.add_two_numbers.cpp`
- `3.longest_substring.cpp`
- `5.longest_palindromic_substring.cpp`
  
## Tentang Saya di LeetCode

Saya aktif mengerjakan berbagai tantangan algoritma dan struktur data di LeetCode, berfokus menjadi problem solver yang tidak hanya "AC", tetapi benar-benar memahami pola dan ide di balik setiap solusi.

## Cara Menjalankan (Windows / g++)

Di root folder repo ini, jalankan perintah berikut di terminal (PowerShell / CMD):

```bash
g++ -std=c++17 -O2 -Wall 1.two_sum.cpp -o two_sum.exe
./two_sum.exe
```

Ganti `1.two_sum.cpp` dan nama output sesuai file yang ingin Anda uji.
